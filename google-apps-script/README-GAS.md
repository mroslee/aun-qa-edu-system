# คู่มือการติดตั้ง Google Apps Script (Backend API)

ไฟล์สคริปต์นี้ทำหน้าที่เป็น **REST API Backend** ให้กับเว็บแอปพลิเคชันระบบประกันคุณภาพหลักสูตร AUN-QA คณะศึกษาศาสตร์ เพื่ออ่านและบันทึกข้อมูลลงใน Google Sheets:
`https://docs.google.com/spreadsheets/d/1V1RVt-2YWWApHWQeYmDqT1ttmZSIldLGgR84k7cW7Q4/edit?usp=sharing`

---

## ขั้นตอนการติดตั้ง (Deployment Steps)

1. เปิด Google Spreadsheet ข้างต้น (หรือไฟล์ที่คุณทำสำเนาไว้)
2. ไปที่เมนูด้านบน คลิก **ส่วนขยาย (Extensions)** -> **Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` ทั้งหมด แล้วคัดลอกโค้ดจากไฟล์ `google-apps-script/Code.gs` ไปวางแทนที่
4. กดปุ่มบันทึกรูปแผ่นดิสก์ (Save) หรือกด `Ctrl + S`
5. คลิกปุ่มสีน้ำเงินด้านขวาบน **ทำให้ใช้งานได้ (Deploy)** -> **การทำให้ใช้งานได้ใหม่ (New deployment)**
6. คลิกที่ไอคอนฟันเฟือง ⚙️ ด้านซ้าย เลือก **เว็บแอป (Web app)**
7. กรอกข้อมูลการเผยแพร่:
   - **คำอธิบาย (Description)**: `AUN-QA API v1.0`
   - **เรียกใช้ในฐานะ (Execute as)**: `ฉัน (Me - your email)`
   - **ผู้มีสิทธิ์เข้าถึง (Who has access)**: **ทุกคน (Anyone)** *(สำคัญมาก เพื่อให้เว็บแอปพลิเคชันที่อยู่บน Vercel สามารถเชื่อมต่อข้อมูลได้)*
8. คลิก **ทำให้ใช้งานได้ (Deploy)**
9. อนุญาตสิทธิ์การเข้าถึง (Authorize access) ด้วยบัญชี Google ของท่าน
10. คัดลอก **URL เว็บแอป (Web App URL)** ที่ได้ ซึ่งจะขึ้นต้นด้วย:
    `https://script.google.com/macros/s/AKfycb.../exec`
11. นำ URL ดังกล่าวไปวางในไฟล์ `js/config.js` ในตัวแปร `APPS_SCRIPT_URL`

## โครงสร้างตารางและแผ่นงานที่รองรับ

ระบบจะทำงานร่วมกับ 4 แผ่นงาน (Tabs) ในสเปรดชีต:
1. **ข้อมูลหลักสูตร**: ข้อมูลทั่วไป, ปรัชญา, วัตถุประสงค์, ELOs/PLOs
2. **รายงาน SAR AUN-QA 8 เกณฑ์**: รายงาน SAR ตามเกณฑ์ AUN-QA เวอร์ชั่น 8 เกณฑ์ พร้อมคะแนนประเมิน (1-7), จุดแข็ง, จุดที่ควรพัฒนา
3. **สถิตินักศึกษา**: จำนวนนักศึกษาแยกตามชั้นปี 1-4+
4. **อาจารย์และผลงานทางวิชาการ**: รายชื่ออาจารย์, คุณวุฒิ, สาขาวิชา, ผลงานทางวิชาการ 5 ปี
