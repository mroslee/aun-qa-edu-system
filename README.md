# ระบบสารสนเทศประกันคุณภาพหลักสูตร AUN-QA คณะศึกษาศาสตร์
### (Faculty of Education - AUN-QA Quality Assurance & Department Tracking System)

ระบบเว็บแอปพลิเคชันสำหรับให้ **แต่ละสาขาวิชา/หลักสูตรเข้ามาบันทึกข้อมูลและประเมินตนเองตามเกณฑ์ AUN-QA 8 ด้าน** และให้ **ฝ่ายประกันคุณภาพการศึกษาของคณะสามารถติดตามความก้าวหน้า (Tracking Matrix) ตรวจสอบความครบถ้วน และประสานงานได้อย่างเป็นระบบ** เชื่อมต่อฐานข้อมูลสดผ่าน **Google Sheets** ด้วย **Google Apps Script** พร้อมสำหรับ Deploy ขึ้น **Vercel** และ **GitHub**

---

## 🌟 ฟังก์ชันการทำงานแยกตามบทบาทผู้ใช้ (Role-based Features)

### 1. สำหรับ "ฝ่ายประกันคุณภาพการศึกษาของคณะ" (QA Division Portal)
- 📊 **หน้าติดตามความก้าวหน้ารายสาขา (QA Progress Tracking)**:
  - สรุปตัวเลข KPI: หลักสูตรทั้งหมด, ส่งรายงานแล้วกี่หลักสูตร (คิดเป็นกี่ %), อยู่ระหว่างกรอก, และค้างส่ง
  - ตารางสถานะรายสาขาวิชา (Status Matrix):
    - หลอดความคืบหน้า (% Completion Bar)
    - จำนวนเกณฑ์ที่ประเมินแล้ว (เช่น 8/8 เกณฑ์)
    - จำนวนเกณฑ์ที่มีลิงก์หลักฐานแนบ (เช่น 8/8 ข้อ)
    - สถานะ (🟢 ส่งรายงานแล้ว / 🟡 กำลังกรอกข้อมูล / 🔴 ยังไม่เริ่ม)
    - ผู้ส่ง/ประธานหลักสูตร และวันเวลาที่อัปเดตล่าสุด
  - ปุ่ม **"ตรวจดู"** เปิดดูรายงาน SAR ฉบับเต็มของสาขานั้นได้ทันที
  - ปุ่ม **"กรอกข้อมูล"** เข้าไปช่วยแก้ไขหรือบันทึกข้อมูลแทนสาขาได้
  - ปุ่ม **"ส่งอีเมลติดตาม"** (Mailto) แจ้งเตือนสาขาวิชาที่ยังค้างส่งพร้อมร่างข้อความให้อัตโนมัติ
  - ปุ่ม **"ส่งออกตารางติดตาม (CSV)"** เพื่อนำไปรายงานต่อที่ประชุมคณะผู้บริหาร

### 2. สำหรับ "สาขาวิชา / ผู้รับผิดชอบหลักสูตร" (Department / Program Chair Portal)
- 🎓 **ระบบกรอกข้อมูลเฉพาะของหลักสูตรตนเอง**:
  - เมื่อเลือกหลักสูตร ระบบจะ **ดึงข้อมูลเดิมที่เคยบันทึกไว้ขึ้นมาแสดงอัตโนมัติ** ไม่ต้องเริ่มพิมพ์ใหม่
  - แถบแสดงความคืบหน้ารวม (% Progress Bar) คำนวณแบบ Real-time ตามฟิลด์ที่กรอก
  - แบ่งเป็น 3 ส่วนหลักอย่างชัดเจน:
    1. **ข้อมูลทั่วไปของหลักสูตร**: ชื่อหลักสูตร, ระดับการศึกษา, ผู้ส่ง, อีเมล, บทสรุปผู้บริหาร, ปรัชญา, วัตถุประสงค์
    2. **ผลการประเมินตนเองตามเกณฑ์ AUN-QA 8 ด้าน**:
       - ให้คะแนนระดับ 1 ถึง 7 พร้อมคำนวณคะแนนเฉลี่ยแบบสด (Real-time Score)
       - ระบุคำอธิบายผลการดำเนินงาน
       - แนบลิงก์ Google Drive หรือเอกสารหลักฐานอ้างอิง
       - ระบุจุดแข็ง (Strengths) และจุดที่ควรพัฒนา (Areas for Improvement)
    3. **สถิตินักศึกษาปัจจุบัน**: กรอกจำนวนนักศึกษา ชั้นปี 1 ถึง 4+ ระบบคำนวณผลรวมให้อัตโนมัติ
  - ปุ่ม 💾 **"บันทึกฉบับร่าง (Save Draft)"** สำหรับบันทึกเก็บไว้ทำต่อในภายหลัง
  - ปุ่ม 🚀 **"ยืนยันส่งรายงานให้ฝ่ายประกันคุณภาพ"** เพื่อส่งข้อมูลเป็นทางการและอัปเดตสถานะในระบบติดตาม

## 🚀 ขั้นตอนการติดตั้ง Google Apps Script

1. เปิดสเปรดชีตข้างต้น
2. ไปที่เมนูด้านบน คลิก **ส่วนขยาย (Extensions)** -> **Apps Script**
3. ลบโค้ดเดิมใน `Code.gs` ทั้งหมด แล้วนำโค้ดในไฟล์ `google-apps-script/Code.gs` ไปวาง
4. กดบันทึก (Save) หรือ `Ctrl + S`
5. คลิกปุ่มสีน้ำเงินด้านขวาบน **ทำให้ใช้งานได้ (Deploy)** -> **การทำให้ใช้งานได้ใหม่ (New deployment)**
6. คลิกไอคอนฟันเฟือง ⚙️ เลือก **เว็บแอป (Web app)**
7. ตั้งค่า:
   - **คำอธิบาย (Description)**: `AUN-QA Tracking API v2`
   - **เรียกใช้ในฐานะ (Execute as)**: `ฉัน (Me)`
   - **ผู้มีสิทธิ์เข้าถึง (Who has access)**: **ทุกคน (Anyone)** *(สำคัญมาก)*
8. คลิก **ทำให้ใช้งานได้ (Deploy)** และให้สิทธิ์เข้าถึง (Authorize access)
9. คัดลอก **URL เว็บแอป (Web App URL)** ที่ได้
10. เปิดหน้าเว็บแอป คลิกไอคอนรูปฟันเฟือง ⚙️ ด้านขวาบน แล้ววาง URL ลงในช่องการตั้งค่า หรือใส่ไว้ในไฟล์ `js/config.js` ในตัวแปร `APPS_SCRIPT_URL`

## 🐙 การอัปโหลดขึ้น GitHub

1. เข้าไปที่ [GitHub.com](https://github.com) สร้าง Repository ใหม่ เช่น `aun-qa-edu-system`
2. ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ไปวางในหน้าเว็บ GitHub:
   - `index.html`
   - โฟลเดอร์ `css/`
   - โฟลเดอร์ `js/`
   - โฟลเดอร์ `google-apps-script/`
   - `vercel.json`
   - `README.md`
3. กดปุ่ม **Commit changes**

## ⚡ การติดตั้งและ Deploy บน Vercel

1. เข้าไปที่ [Vercel.com](https://vercel.com) แล้ว Log in ด้วยบัญชี GitHub
2. คลิกปุ่ม **Add New...** -> **Project**
3. เลือก Repository `aun-qa-edu-system` แล้วคลิก **Import**
4. คลิกปุ่ม **Deploy**
5. ระบบจะสร้างลิงก์เว็บไซต์ให้คุณทันที เช่น `https://aun-qa-edu-system.vercel.app` สามารถส่งลิงก์นี้ให้ประธานหลักสูตรทุกสาขาวิชาเข้ามาบันทึกข้อมูลได้ทันที!
